ТРИ ЛЕНДИНГА ПО РЕФЕРЕНСАМ
Готовый автономный комплект. 06.11.2026

ОТКРЫТЬ
Дважды щёлкните index.html. Интернет, установка библиотек и сборка не нужны.
Отдельные страницы: fleur.html, sense.html, kyoto.html, norma.html (кейс), opara/index.html (сайт пекарни).
norma.html и opara подгружают шрифты Inter и Onest с Google Fonts; без интернета подставятся системные.
Все изображения, кириллические шрифты, CSS и JavaScript лежат в assets/.

ЛОКАЛЬНЫЙ СЕРВЕР (необязательно)
Если установлен Node.js: node server.mjs
Адрес: http://127.0.0.1:4173
Другой порт: node server.mjs 4174
Если установлен Python: python -m http.server 4173 --bind 127.0.0.1
Для Windows также можно использовать start-server.cmd.
Остановка сервера: Ctrl+C в его окне.

ПЕРЕДАЧА
Передавайте папку целиком либо общий ZIP. Не переносите HTML отдельно от assets.
Три PDF лежат рядом с HTML-страницами и также включены в полный архив.
PDF — длинные одностраничные макеты всей страницы, анимация есть только в HTML.

ЧТО РАБОТАЕТ
Навигация по секциям, мобильное меню, появление блоков при прокрутке,
движение декоративных деталей, карточки с описанием и выбором размера,
демонстрационные формы с проверкой заполнения, возврат наверх.
Учитываются системные настройки уменьшения движения.
Формы не отправляют данные; оплаты и настоящего оформления заказов нет.
Откройте страницу и прокрутите вниз, чтобы увидеть анимацию.

ИСХОДНИКИ И ПРАВА
Неофициальные учебные концепты по предоставленным скриншотам.
Названия брендов сохранены как часть задания. Не официальные сайты брендов.
Иллюстративные фотографии сгенерированы встроенным ImageGen, без копирования
оригинальных фотографий из референсов. Полные промпты — в ASSETS-AND-PROMPTS.txt.
Цены первого макета взяты из референса и не являются коммерческим предложением.
Golos Text, Oswald, Caveat — Google Fonts, SIL Open Font License.
Лицензии находятся в assets/fonts/.
Анимации написаны на CSS и IntersectionObserver без сторонних библиотек.
